# Comparison Operators

| Operator | Meaning                  |
| :------: | ------------------------ |
|    `>`   | Greater than             |
|    `<`   | Less than                |
|   `>=`   | Greater than or equal to |
|   `<=`   | Less than or equal to    |
|   `===`  | Equal to                 |
|   `!==`  | Not equal to             |

# Difference between === & ==

| `==`  | looses equality and do type-cast to match data    |
| `===` | strict equality and don't type-cast to match data |
